## 模型调用工具编排

* 循环不收敛：模型反复调用同一工具、同一参数，或每一步都“快完成了”但永远不结束。
* 并行失控：无依赖的工具被串行执行，延迟叠加；或者并行的工具之间存在隐式依赖，结果互相污染。
* 失败处理一刀切：所有异常统一重试三次，对幂等查询是浪费，对退款操作则是制造重复扣款。
* 降级无路可走：工具全部不可用时，要么抛 500，要么让模型面对“调用失败”继续盲目尝试

---
* 多轮调用的收敛控制：


* max_turns	限制模型决策轮次	生产 Agent 5–15，编码 Agent 可到 50+，但必须有
* max_tool_calls	限制工具执行总次数	按工具危险等级分档
* max_tokens / 成本上限	防止上下文膨胀和费用失控	每轮检查，超限即熔断
* max_seconds（wall time）	兜底延迟	用户可感知的等待阈值

#### 死循环
* 精确重复：同一工具 + 同一参数哈希连续出现 ≥3 次 → 触发熔断，向模型返回 repeat_detected，附带“换参数或换工具”的指令。

* 幽灵循环：连续多轮上下文哈希不变、模型输出语义等价但措辞不同 → 判定为空转，强制结束并返回当前最佳结果。


```python
# 自定义中间件
from langchain.agents import create_agent
from langchain.agents.middleware import AgentMiddleware, ToolCallLimitMiddleware
from langchain_core.messages import ToolMessage
import hashlib, json
from collections import deque

# 用于解决精确重复中间件
class ExactRepeatMiddleware(AgentMiddleware):
    def __init__(self, window_size=10, threshold=3):
        self.window = deque(maxlen=window_size)
        self.threshold = threshold

    @staticmethod
    def _hash(tool_name, tool_args):
        sorted_args = json.dumps(tool_args, sort_keys=True, separators=(',', ':'))
        return hashlib.sha256(f"{tool_name}:{sorted_args}".encode()).hexdigest()

    def wrap_tool_call(self, tool_call, handler):
        h = self._hash(tool_call["name"], tool_call.get("args", {}))
        self.window.append(h)
        if self.window.count(h) >= self.threshold:
            return ToolMessage(
                content="[repeat_detected] 同一工具与参数已连续重复调用。请更换参数或更换工具。",
                tool_call_id=tool_call["id"],
            )
        return handler(tool_call)

# 原生配额限制
quota = ToolCallLimitMiddleware(run_limit=25, exit_behavior="end")

agent = create_agent(
    model=llm,
    tools=tools,
    middleware=[ExactRepeatMiddleware(threshold=3), quota],
)

# 用于解决幽灵循环中间件
from loopguard import LoopGuardCallbackHandler
handler = LoopGuardCallbackHandler()
result = agent.invoke(
    {"messages": [("user", query)]},
    config={"callbacks": [handler], "recursion_limit": 15},
)
```
