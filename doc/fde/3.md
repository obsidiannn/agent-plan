* mcp认证
    * pat: personal access token
    * oauth2.1: mcp 规范明确要求
        * 时效较短
        * 强制pkce: (验证密钥交换)
        * 受众绑定（RFC 8707 Resource Indicators）：令牌明确标注「只给某个 MCP 服务器用」，服务器必须校验令牌确实是签发给自己的，杜绝「令牌透传」滥用。
        * 元数据发现与动态注册（RFC 8414 / 7591 / 9728）：客户端能自动发现授权服务器、自动注册，无需人工把一堆参数抄来抄去。
    * oauth2.0: 兼容老版本
        * 可选pkce
